🧠 PRESENCIA v1.2 — conectar IA gratuita

El modelo de IA se ejecuta en tu computadora Windows mediante Ollama. Las Quest 3 siguen utilizando Vosk para escucharte y Piper para hablar. No hay cargos por API.

La PC debe permanecer encendida, conectada a Internet, con Ollama y dos ventanas de PowerShell abiertas durante la prueba. El primer modelo ocupa aproximadamente 1 GB de descarga. Usamos qwen2.5:1.5b para empezar con pocos recursos; no es el mismo modelo que ChatGPT.

Paso 1 — Instalar tres programas en la computadora

En Windows presioná Win + X → Terminal/PowerShell. Pegá cada comando y presioná Enter. Si ya tenés alguno instalado, omitilo. Es probable que Windows te pida confirmar permisos.

Ollama — ejecuta la IA:

winget install -e --id Ollama.Ollama

Python 3 — ejecuta nuestro puente seguro:

winget install -e --id Python.Python.3.13

cloudflared — crea una dirección HTTPS temporal gratuita:

winget install -e --id Cloudflare.cloudflared

Cerrá y volvé a abrir PowerShell después de instalar.

Paso 2 — Descargar el modelo gratuito

Con Ollama abierto, pegá:

ollama pull qwen2.5:1.5b

Cuando termine, hacé una prueba en la PC:

ollama run qwen2.5:1.5b

Escribí Hola y comprobá que responda. Para salir de esa conversación, escribí /bye. No cierres Ollama.

Paso 3 — Iniciar el puente de PRESENCIA

Abrí PowerShell en una carpeta cómoda. Estos comandos crean una carpeta nueva y descargan el archivo desde tu propio GitHub:

mkdir PRESENCIA
cd PRESENCIA
curl.exe -L "https://raw.githubusercontent.com/rygarmdq/quest-presencia/main/presencia_puente.py" -o presencia_puente.py
py presencia_puente.py

Si mkdir PRESENCIA responde que la carpeta ya existe, usá solamente cd PRESENCIA. El programa mostrará una CLAVE SECRETA en la pantalla. No compartas esa clave ni cierres la ventana.

Si py no funciona, probá python presencia_puente.py. La clave es distinta cada vez que reiniciás el programa.

Paso 4 — Crear la conexión HTTPS

Abrí una segunda ventana de PowerShell (sin cerrar la anterior) y ejecutá:

cloudflared tunnel --url http://localhost:8765

Buscá una dirección parecida a https://algo-aleatorio.trycloudflare.com y copiala. Cambia cada vez que reiniciás cloudflared.

Paso 5 — Hablar con PRESENCIA en las Meta Quest 3

  1. Abrí PRESENCIA v1.2 BETA en las Quest 3.
  2. En IA LOCAL, pegá la dirección HTTPS del paso 4 y la clave del paso 3.
  3. Presioná CONECTAR IA. Debería aparecer IA CONECTADA.
  4. Presioná PREPARAR VOSK + PIPER y esperá que estén listos.
  5. Entrá en realidad mixta, presioná MICROFONO y preguntá: «¿Por qué el cielo es azul?».
  6. Después preguntá: «¿Me lo explicás con un ejemplo?». La IA debería recordar el contexto inmediato.

Los comandos esfera, holograma y humanoide siguen funcionando sin la IA.

Privacidad y seguridad

La IA funciona localmente, pero los mensajes de la aplicación pasan por un túnel HTTPS de Cloudflare antes de llegar a tu PC. El puente está protegido con una clave temporal y solo responde al origen web del proyecto. No publiques la clave, no abras el puerto de Ollama en el router y no uses datos confidenciales en el prototipo.

Cloudflare Quick Tunnel es una solución temporal de pruebas, no para producción. Al cerrar cloudflared o el puente, termina la conexión; eso es lo recomendable después de cada sesión.

Si aparece un error

IA SIN CONEXIÓN: comprobá URL HTTPS y clave. Si reiniciaste el túnel, copiá la URL nueva.

Modelo no encontrado: volvé al paso 2.

La IA tarda: el modelo puede estar funcionando solo con CPU. Dejá que termine; respuestas breves ayudan.

Micrófono y voz siguen funcionando, pero sin IA: no se pierde lo anterior. Podés volver a PRESENCIA v1.1 estable.
